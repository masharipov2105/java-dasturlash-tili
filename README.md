## About This Repository

This is my personal **Java learning journal** — not a library, not a framework, 
not a tool. It is a **verifiable proof of my learning journey**, captured in 
commits.

For approximately **2.5 months**, I have been studying Java Core from absolute 
zero and documenting every concept I learned by writing code, experimenting with 
it, and committing the results. Some days I committed several times; some days 
I could not commit at all — but the goal has always remained the same: 
**learn something new every single day**.

Every folder in this repository represents a topic I studied. Every `Main.java` 
file is a small experiment — code I wrote to *see with my own eyes* how a class, 
method, or concept behaves. This is not production code. This is my learning 
process, made visible.

### A Note on Language

**All code comments and in-code documentation are written in Uzbek.** 
This repository is primarily intended to help **Uzbek-speaking learners** 
who are starting their Java journey — just like I did. The README is in English 
for international visibility, but the code itself speaks Uzbek.

I am sharing this openly because I believe **learning in public** is the most 
honest way to grow — and because I want other beginners from my country to have 
a commented, working reference they can actually read.

## How to Run

Each example is a **standalone** `Main.java` file — no build tool, no 
dependencies, no setup required. You only need **JDK 17** installed.

```bash
# 1. Clone the repository
git clone https://github.com/masharipov2105/java-dasturlash-tili.git
cd java-dasturlash-tili

# 2. Navigate into any topic folder, for example:
cd OOP/Polimarfizm-tushunchasi

# 3. Compile and run
javac Main.java
java Main
```
