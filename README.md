Mening Java tilini o'rganish jarayonida yozgan kodlarim.

## Bu nima?

Bu repozitoriy - Java tilini o'rganish davrida yozgan barcha kodlarimning to'plami. Bu yerda hech qanday tayyor dastur yoki loyiha yo'q. Faqat men o'rgangan mavzular bo'yicha sinab ko'rgan, tekshirib ko'rgan kod misollarim bor.

## Nima maqsadda?

Bu repozitoriy mening Java tilini o'rganish jarayonimni ko'rsatish uchun. CV yoki portfolio sifatida foydalanish mumkin. Ish beruvchi yoki hamkasblarim Java tilini qanday o'rganganimni, qaysi mavzularni ko'rib chiqqanimni ko'rishlari mumkin.
